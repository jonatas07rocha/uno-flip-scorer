# 🃏 UNO Flip! Scorer

Uma aplicação web moderna, responsiva e elegante para marcar e gerenciar pontuações de partidas de **UNO Flip!** com regras oficiais Mattel.

![UNO Flip! Scorer Banner](https://img.shields.io/badge/UNO--Flip!-Scorer-indigo?style=for-the-badge&logo=appveyor)
![Licença](https://img.shields.io/badge/Licen%C3%A7a-MIT-emerald?style=for-the-badge)

## 🚀 Funcionalidades

- **🏆 Placar em Tela Cheia Automático**: Ao confirmar uma rodada, o placar atualizado é exibido em destaque em tela cheia até você mover o mouse ou clicar/tocar na tela.
- **🃏 Calculadora de Cartas de Ação**: Botões dedicados para pontuação oficial das cartas de ação (*Comprar 1*, *Comprar 5*, *Inverter*, *Pular*, *Virar*, *Pular Todos*, *Curingas*, etc.).
- **🌗 Suporte a Light Mode e Dark Mode**: Troca automática acompanhando o tema do seu dispositivo, com alternador manual.
- **✏️ Edição de Nome dos Jogadores**: Altere o nome de qualquer jogador durante a partida sem perder os pontos acumulados.
- **🔊 Efeitos Sonoros e Confetes**: Efeitos sintéticos via Web Audio API e celebração visual de vitória com confetes.
- **💾 Salvamento Automático**: Progresso e histórico armazenados no `localStorage` do navegador.

## 🛠️ Tecnologias Utilizadas

- **HTML5 & CSS3**
- **Tailwind CSS** (via CDN)
- **JavaScript ES6+**
- **Lucide Icons**
- **Canvas Confetti**
- **Web Audio API**

## 🌐 Implantação na Vercel

Esta aplicação é um site estático. Para implantar na Vercel:

1. Faça o push deste repositório para o **GitHub**.
2. Acesse [vercel.com](https://vercel.com) e clique em **"Add New Project"**.
3. Importe o repositório do GitHub.
4. Clique em **"Deploy"** (não requer comandos de build).
